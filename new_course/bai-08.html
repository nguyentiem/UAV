01 · Nền tảng

Tách mô hình khỏi bộ tích phân

Một hàm f(x,u) thuần nhận trạng thái và đầu vào, trả đạo hàm; nó không tự sửa trạng thái toàn cục. Nhờ vậy cùng mô hình có thể chạy Euler, RK4, unit test và tối ưu tham số. Trạng thái gồm p(3), v(3), q(4), ω(3); q có ràng buộc chuẩn 1 nên thực chất hệ vẫn có 12 bậc tự do trạng thái vật lý.

Công thức: Đặt đơn vị SI tại ranh giới vào/ra; không đưa độ vào sin/cos của numpy.

RK4 tính trung bình độ dốc

Euler dùng độ dốc đầu bước nên lệch khi lực/mô men đổi nhanh. RK4 tính bốn độ dốc ở đầu, giữa và cuối bước, rồi lấy trung bình có trọng số. Mô hình motor có độ trễ nên cần thêm trạng thái tốc độ motor thay vì giả định lệnh ESC đổi lực tức thời. Sau bước tích phân, chuẩn hóa quaternion.

Thử nghiệm có nghiệm biết trước

Trong rơi tự do từ đứng yên, z(t)=z0−gt²/2 nếu bỏ cản. Hover lý tưởng giữ z và vận tốc bằng 0. Với mô men roll hằng nhỏ và Jx không đổi, φ(t)≈τxt²/(2Jx). Ba kết quả này là mốc để bắt lỗi dấu, đơn vị và tích phân trước khi thêm estimator/controller.

03 · Thực hành

Làm theo ba bước

1
Chuẩn bị. Bài 2, 3, 4; Python và numpy. Ghi quy ước hệ trục, đơn vị và giả thiết.
2
Thực hiện. hướng dẫn từng bước kèm code Python hoàn chỉnh (chia thành các file/hàm nhỏ), mỗi bước có kết quả mong đợi và cách kiểm tra.
3
Kiểm tra. So sánh kết quả với ca giới hạn hoặc giá trị có thể tính tay; ghi sai số và lý do nếu lệch.
Code tham khảo
import numpy as np
def deriv(state, thrust, mass=1.2):
    z, vz = state
    return np.array([vz, thrust/mass-9.81])
def rk4(f, x, dt, *args):
    a=f(x,*args); b=f(x+dt*a/2,*args)
    c=f(x+dt*b/2,*args); d=f(x+dt*c,*args)
    return x+dt*(a+2*b+2*c+d)/6
x=np.array([0.,0.])
for _ in range(1000): x=rk4(deriv,x,.01,1.2*9.81)
print(x)  # hover lý tưởng: gần [0,0]

Đoạn code là ví dụ tối giản cho bước thực hành; xem chú thích và kiểm tra đơn vị trước khi đưa vào hệ thống thật.
